هاوڕێ — وەشانی ٤
پلاتفۆرمی فرەزمان بۆ عادەتەکانی خوێندن، ڕاهێنان و پشتگیری

نوێ لە وەشانی ٤
- فۆنتی Speda.ttf ی نێردراوی بەکارهێنەر لە public/fonts/Speda.ttf دانراوە.
  ڕووکار، خانەکانی نووسین و چاپ بەکاری دەهێنن؛ بۆ پیتە نەبووەکان
  فۆنتی سیستەم بەکاردێت. هیچ فۆنتێک لە خزمەتگوزاری دەرەکی بار ناکرێت.
- هەڵبژاردەی زمان لە سەرەوەی پەڕە و ڕێکخستنەکان هەیە: کوردی سۆرانی،
  کوردی کورمانجی (لاتینی)، عەرەبی، ئینگلیزی و فارسی.
- ٧٦٧ پەیامی ڕووکار/ناوەڕۆکی فێربوون بۆ هەر یەک لە چوار زمانی زیادکراو
  وەرگێڕدراون، لەگەڵ پرسیار، پێشنیار، ڕاپۆرت، هێڵکار و دەقی داگیراو.
- سۆرانی/عەرەبی/فارسی RTL؛ کورمانجی/ئینگلیزی LTR. دەربڕینی بیرکاری
  LTR دەمێنێت. بەروار و ناونیشانی پەڕەش بەپێی زمان دەگۆڕێن.
- زمان لە hawre:language دەپارێزرێت و لە پاشەکەوتی JSON شدا هەیە.
  گۆڕینی زمان و New Form ناو، وەڵام و تێبینیی نووسراوی خۆت وەرناگێڕن.
  New Form وەڵامەکانی فۆڕم پاک دەکات و هەڵبژاردنی زمان دەپارێزێت.
- بابەت/ئامانجی خۆکاری ڕێگای فێربوون بە نیشانەی سەرچاوە پاشەکەوت دەبن
  و لە گۆڕینی زماندا وەرگێڕدرێن. بە دەستکاریکردنی خانەکە دەقەکەت
  کەسی دەبێت و هەمان شێوەی نووسراوی خۆت دەپارێزێت.
- فۆنت و زمانەکان لە وەشانی production دوای یەکەم باربوون offline ش
  بەردەستن. نوێکردنەوەی خزمەتگوزاری offline پاشەکەوتی قوتابی ناسڕێتەوە.

ئەم وەشانە چی زیاد دەکات؟
١. نمرەدانی ڕوون: درێژی نووسین، کاتژمێری خوێندن، ژینگە و هەڵبژاردنی
   شێوازی یارمەتی نمرە نادرێن. نیشاندەرەکان support-v2 ن و ڕێژەی
   نەخۆشی یان پێوانەی پزیشکی نین. مێژووی کۆن بە legacy-v1 دەپارێزرێت
   و لەگەڵ یاسای نوێ بەراوردی ژمارەیی ناکرێت.
٢. ڕێگای فێربوون: پشکنینی سەرەتا، نموونە، ڕاهێنان بە یارمەتی، پرسیاری
   سەربەخۆ، ڕوونکردنەوەی خۆت و پشکنینی نوێ دوای لانیکەم ٢٤ کاتژمێر.
   هەوڵی یەکەم دەپارێزرێت. دڵنیایی و نووسین نمرەی دروستی وەڵام ناگۆڕن.
٣. سێ بابەتی گشتی: کەرتەکان، هاوکێشەی سادە و تێگەیشتن لە دەقی سۆرانی.
   ئەمانە بەرنامەی پەسەندکراوی قوتابخانە نین. داگرتنی ناوەڕۆک بۆ
   پێداچوونەوەی مامۆستا لە ناو بەشی فێربووندا هەیە، بەبێ زانیاریی قوتابی.
٤. دووبارەکردنەوە: کارتی یادخستنەوە پێش پیشاندانی وەڵام، نۆرەی گەڕانەوە
   و تۆماری هەڵە بە هەوڵی نوێ. هەڵسەنگاندنی کارت و هەڵە لەلایەن خۆتە؛
   نمرەیەکی سەربەخۆی تێگەیشتن نییە. ماوەکانی١/٣/٧/١٤/٣٠ ڕۆژ یاسایەکی
   دەستپێکی ناوخۆیین، نە ڕێژەیەکی تاکەکەسیی پشتڕاستکراو.
٥. پشتگیری بەپێی هۆکار: تێنەگەیشتن، دەستپێکردن، کات، ژینگە و ماندووبوون
   هەنگاوی جیاواز وەردەگرن. تەنها کات/ماندووبوون کاتی ئەرکی داهاتوو کەم دەکەن.
٦. داواکاری یارمەتی بۆ کەسێکی متمانەپێکراو، پشووی ئارەزوومەندانە، تێبینیی
   بەسوودبوون بە ڕەزامەندی. هیچ نامەیەک خۆکار نانێردرێت و چاودێری نییە.

تایبەتمەندییە پێشووەکان: هەمان ١٦ پرسیاری سۆرانی، پشکنینی وەڵامەکان،
پاشەکەوت و گەڕاندنەوە، پلانی ٧ ڕۆژ، خشتە، کاتژمێر، ڕاپۆرت، هێڵکار،
چاپ/PDF، دەق، هاوبەشکردنی هەڵبژێردراو، دۆخی تاریک، دەقی گەورەتر و offline.

بۆ بینینی وەشانی ئامادەکراو (Node.js پێویستە):
  node scripts/serve.mjs
  http://127.0.0.1:4173

بۆ گەشەپێدان (Node.js 20.19+ یان 22+):
  npm install
  npm run dev

بۆ پشکنین و دروستکردنەوە:
  npm test
  npm run build
  npm run preview

dist/ لە پاکێجەکەدا ئامادەیە. لە سێرڤەری HTTPS لە ڕەگی دۆمەین دابنرێت؛
ژێرڕێڕەو وەک /study/ لەم وەشانەدا ڕێک نەخراوە. index.html بە دووکلیک
کردن کار ناکات؛ سێرڤەری HTTP/HTTPS پێویستە. Offline دوای یەکەم باربوونی
سەرکەوتووی وەشانی production کار دەکات، نە یەکەم سەردان بەبێ پەیوەندی.

گواستنەوە و نهێنی
هەژمار، backend، AI، چاودێریکردن و هاوکاتکردنەوەی خۆکاری ئامێرەکان نییە.
پاشەکەوتی وەشانی٢ و٣ قبوڵ دەکرێت؛ خانەکانی نوێ بە بنەڕەت پڕ دەکرێنەوە.
New Form تەنها وەڵامەکانی فۆڕم پاک دەکات؛ Delete All هەموو زانیارییەکانی
ئەم ئەپە لەم وێبگەڕە دەسڕێتەوە. فایلەکانی JSON نهێنی/کۆدکراو نین.
کاتژمێری ناتەواو بە جێهێشتنی بەشەکە ڕادەوەستێت. دانیشتنی تەواوکراو
تەنها جارێک تۆمار دەکرێت. هەوڵەکانی فێربوون و ڕوونکردنەوەش پاشەکەوت دەبن.
