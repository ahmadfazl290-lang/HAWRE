تایبەتمەندییەکان
- هەمان ١٦ پرسیار و یاسای نمرەدان و پێشنیارەکانی سەرچاوەی سەرەکی.
- پشکنینی وەڵام لە هەر بەش، پاشەکەوت و گەڕاندنەوە، ڕاپۆرت و چاپ/PDF.
- پلانی کەسیی ٧ ڕۆژە بەپێی کات، وانە، ژینگە و وەڵامەکان.
- تەواوکردنی ئەرک، گۆڕینی کات، بەدواداچوونی ڕۆژانە و ئاسانکردنی پلان.
- کاتژمێری سەرنجدان/پشوو، کارتی پرسیار و وەڵام، خشتە و تۆماری هەڵە.
- هێڵکاری چالاکی، مێژووی هەڵسەنگاندن و بینینی خاڵە بەهێزەکان.
- هەڵبژاردنی زانیاری بۆ هاوبەشکردن، پاشەکەوت و گەڕاندنەوەی JSON.
- دۆخی تاریک، دەقی گەورەتر، مۆبایل و دەستڕاگەیشتن بە کیبۆرد.
- کارکردن بەبێ ئینتەرنێت دوای یەکەم باربوونی وەشانی بەرهەمهێنراو.

ڕێنمایی بۆ گەشەپێدەر
ئەمە پرۆژەیەکی تەواوی React / Tailwind / Recharts ـە.
Node.js 20.19+ یان 22+ بەکاربهێنە؛ لە ناو فۆڵدەری پرۆژە:

  npm install
  npm run dev

بۆ وەشانی ئامادەکراو:

  npm run build
  npm run preview

پاشان http://127.0.0.1:4173 بکەرەوە.
فۆڵدەری dist/ ئێستا دروستکراوە؛ بۆ تەنها بینینی وەشانی ئامادەکراو،
بە Node.js و بەبێ دامەزراندنی پاکێجەکان دەتوانیت ئەمە جێبەجێ بکەیت:

  node scripts/serve.mjs

بۆ دامەزراندن لە سێرڤەر، ناوەڕۆکی dist/ لە ڕەگی دۆمەینێکی HTTPS دابنێ.
فایلەکانی dist بە دووکلیک کردن لە index.html کار ناکەن؛ HTTP/HTTPS پێویستە.
دامەزراندن لە ژێرڕێڕەو (وەک /study/) لەم وەشانەدا ڕێک نەخراوە.
کارکردنی offline تەنها لە build/preview یان HTTPS دامەزراو تاقی بکرێتەوە.
کاتژمێری ناتەواو بە جێهێشتنی بەشی ئامرازەکان/نوێکردنەوە ڕادەوەستێت؛
تەنها دانیشتنە تەواوکراوەکان لە مێژوودا تۆمار دەکرێن.

تێبینییەکانی زانیاری
هەژمار و backend و AI نییە. پلانەکان بە یاسای ناوخۆیی ڕێک دەخرێن.
زانیارییەکان لە هەمان ئامێر/وێبگەڕن؛ گواستنەوە بە فایل دەکرێت.
New Form تەنها وەڵامەکانی فۆڕم پاک دەکات؛ Delete All هەموو زانیارییەکانی
ئەم ئەپە دەسڕێتەوە. پاشەکەوتی JSON زانیارییە کەسییەکانیش دەگرێتەوە.
هەموو ڕێژەکان هەمان یاساکانی نمرەدانی سەرچاوەن و پێوانەی پزیشکی نین.
ڕێژەی کەمتر نیشانەی کێشەی کەمترە لە وەڵامەکان، نە نمرەی قوتابخانە.
